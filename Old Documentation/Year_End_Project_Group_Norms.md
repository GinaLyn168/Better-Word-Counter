To share files electronically, we will work together on a private GitHub repo where both of us can collaborate.

Commits, pushes, and pulls will be used in order for both memebers to stay up to date with code changes and team progres.

### Defined Group Norms

- All project-related messages must be acknowledged within 24 hours. A brief "received" or "will check later" is required to maintain momentum.

- All official project coordination and quick-syncs will occur via iMessage.

- GitHub will be the sole repository for the project. All code, README files, and project documentation must be hosted here.

- Every commit must be accompanied by a clear, descriptive message explaining exactly what was changed or added to the codebase.

- No partner shall push code to the main branch that is incomplete or prevents the program from compiling/running. Shared code must remain functional at all times.

- Any data used during development, especially if involving real-world "clients" or users, must be handled securely and kept confidential.

- If a deadline or task cannot be met, the partner responsible must notify the other the day of the deadline at the latest to allow for contingency planning.

- Feedback on code or documentation must be objective and focused on improving the project’s quality and meeting technical requirements.

- The workload will be shared equally. Tasks will be distributed based on a 50/50 split regarding time commitment and technical complexity.

- Both partners are responsible for maintaining up-to-date documentation within the GitHub repository as the project progresses, ensuring it meets standard technical requirements.
